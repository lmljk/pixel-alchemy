# 第四天蒸汽、熔岩与酸液设计

## 目标

第四天在已有八种材料、画笔、暂停、单步和分享链接的基础上，增加三种更有戏剧性的材料：

1. 蒸汽向上漂浮并可能冷凝成水。
2. 熔岩缓慢流动，遇水变石头并把水变蒸汽，也能点燃可燃物。
3. 酸液像液体流动，并腐蚀有限范围内的固体与植物。

本阶段的重点是让 demo 更好玩，而不是追求真实物理。实现仍保持纯前端、无后端、无 API Key、无数据库、无登录、无上传、无额外浏览器权限。

## 第四天范围

### 包含

- 三种新材料：
  - 蒸汽
  - 熔岩
  - 酸液
- 材料编号、中文名称、颜色、类别和可燃性定义更新
- 蒸汽上升与随机冷凝
- 熔岩遇水、点燃和慢速流动
- 酸液腐蚀与液体流动
- 分享格式升级为 `v2`
- 旧 `v1` 分享链接明确失效并安全回退
- 页面阶段标签更新为“试验 04”
- 桌面和手机浏览器验收
- 新规则的确定性单元测试

### 不包含

- 兼容或迁移第三天 `v1` 分享链接
- 温度场、压力场、粘度场或连续流体
- 烟、灰烬、玻璃、金属等更多材料
- 笔刷尺寸选择
- 撤销与重做
- 时间轴回放
- 短链接服务或云端作品库
- 部署流程调整

旧链接失效是用户确认过的取舍。这样第四天可以直接锁定新的材料编号和规则版本，避免为了早期 demo 维护复杂迁移。

## 材料模型

网格继续使用一维 `Uint8Array`。材料编号升级为：

| 编号 | 材料 | 类别 | 主要行为 |
| --- | --- | --- | --- |
| `0` | 空 | 空间 | 可被其他材料占据 |
| `1` | 沙子 | 粉末 | 下落，受阻后斜滑 |
| `2` | 水 | 液体 | 下落、横流，并可与油交换 |
| `3` | 墙 | 固定固体 | 不移动，可被酸液腐蚀 |
| `4` | 石头 | 重固体 | 只垂直下落，可被酸液腐蚀 |
| `5` | 木头 | 固定可燃固体 | 可被火或熔岩点燃，可被酸液腐蚀 |
| `6` | 油 | 可燃液体 | 流动，可被火或熔岩点燃 |
| `7` | 火 | 短寿命反应体 | 上漂、点燃木头/油/植物、随机熄灭 |
| `8` | 植物 | 固定生长体 | 接触水时扩展，可燃，可被酸液腐蚀 |
| `9` | 蒸汽 | 气体 | 上升，随机冷凝为水 |
| `10` | 熔岩 | 热液体 | 遇水变石头并产蒸汽，点燃可燃物，缓慢流动 |
| `11` | 酸液 | 腐蚀液体 | 腐蚀墙、石头、木头和植物，之后一起消失 |

橡皮仍不是材料编号。界面选择橡皮时继续写入 `Material.Empty`。

## 材料规则

### 蒸汽

蒸汽每步先进行冷凝判定：

1. 调用一次随机源得到 `steamRoll`。
2. 当 `steamRoll < 0.08` 时，当前蒸汽直接变成水，本步结束。
3. 未冷凝时，蒸汽优先向正上方空位移动。
4. 正上方不可用时，使用同一个 `steamRoll` 决定斜上方向：`steamRoll < 0.54` 时先左上，否则先右上。
5. 两个斜上方向都不可用时保持原位。

蒸汽不向下移动，也不主动与火、酸液或熔岩反应。冷凝出的水标记为本步已处理，避免同一步继续下落。

### 熔岩

熔岩的反应优先于移动：

1. 收集四邻域中的水。若存在水，选择一个目标水单元，将该水变为蒸汽，将当前熔岩变为石头，本步结束。
2. 若没有水，收集四邻域中的木头、油和植物。若存在目标，选择一个并点燃为火，当前熔岩保持原位，本步结束。
3. 若没有可反应目标，调用一次随机源得到 `lavaMoveRoll`。
4. 当 `lavaMoveRoll >= 0.35` 时，熔岩保持原位。
5. 当 `lavaMoveRoll < 0.35` 时，熔岩按液体规则尝试流动：正下方、斜下方、同一行最多三格横向搜索。

熔岩移动的方向选择沿用液体的随机方向机制，但只有通过慢速移动门槛后才会执行。熔岩不会与油交换，也不会被水主动处理；水与熔岩的变化由熔岩规则触发，保证相同扫描顺序下结果可测试。

熔岩点燃的新火标记为本步已处理，不能在同一步继续点燃或移动。熔岩遇水产生的新蒸汽和新石头也标记为本步已处理。

### 酸液

酸液同样先反应再移动：

1. 收集四邻域中的墙、石头、木头和植物。
2. 若存在目标，选择一个目标单元，将目标变为空，并将当前酸液也变为空，本步结束。
3. 若没有目标，酸液按液体规则尝试流动：正下方、斜下方、同一行最多三格横向搜索。

酸液只腐蚀墙、石头、木头和植物。它不腐蚀沙子、水、油、火、蒸汽、熔岩、酸液或空单元。酸液不会点燃、不会熄灭火，也不会和水发生中和反应。

酸液腐蚀时，目标和酸液来源都标记为本步已处理。即使来源变为空，也避免同一步被旁边材料立刻占用后再次参与反应。

## 既有规则保持

沙子、水、墙、石头、木头、油、火和植物保留第三天行为。只有两处可见变化：

- 火的可燃目标仍然是木头、油和植物；蒸汽、熔岩和酸液不加入火的可燃目标。
- 水遇到熔岩时不主动变化；变化由熔岩扫描到水时触发。

这让新增材料尽量局部化，降低回归风险。

## 随机调用顺序

第四天继续使用 `SeededRandom`，分享链接仍保存下一次随机状态和下一步扫描方向。新增规则必须保持固定调用顺序：

- 蒸汽每次处理必定消耗一次随机值，用于冷凝和斜上方向。
- 熔岩存在相邻水时，只有选择多个候选目标需要消耗随机值；单个目标不消耗选择随机值。
- 熔岩存在相邻可燃物时，只有选择多个候选目标需要消耗随机值；单个目标不消耗选择随机值。
- 熔岩没有反应目标时，必定消耗一次 `lavaMoveRoll`；只有 `lavaMoveRoll < 0.35` 才继续进入液体移动方向选择。
- 酸液存在多个腐蚀目标时消耗随机值选择目标；单个目标不消耗选择随机值。
- 酸液无腐蚀目标时沿用液体移动的随机调用顺序。

测试要锁定这些调用路径，避免将来一次无意的随机调用破坏分享后的确定性。

## 存档格式

分享链接继续使用：

```text
#share=<base64url payload>
```

第四天将格式版本升级为 `2`。二进制头部暂不扩展，仍为 10 字节：

| 字节 | 内容 |
| --- | --- |
| `0` | 格式版本，第四天固定为 `2` |
| `1..2` | 网格宽度，无符号 16 位大端序 |
| `3..4` | 网格高度，无符号 16 位大端序 |
| `5..8` | PRNG 状态，无符号 32 位大端序 |
| `9` | 标志位；bit 0 表示下一步从左向右扫描，其余位必须为零 |
| `10..` | RLE 数据，每组为材料编号 `uint8` + 连续长度 `uint16` |

解码只接受版本 `2`。版本 `1` 链接视为无效链接，页面显示现有的无效分享提示并打开空白画布。材料编号合法范围升级为 `Material.Empty..Material.Acid`。

版本 `2` 同时锁定材料编号、蒸汽/熔岩/酸液规则、PRNG 算法和扫描方向语义。未来再发生不兼容变化时继续增加版本。

## 渲染

Renderer 继续从材料定义读取颜色，并保持同一网格渲染结果稳定：

- 蒸汽：浅蓝白、半透明感的冷色调
- 熔岩：红、橙、亮黄色高热感
- 酸液：荧光绿、黄绿色

颜色变化仍只依赖网格索引和材料编号，不调用随机源。

## 错误与权限

第四天不引入新的浏览器权限。分享仍只依赖 `navigator.clipboard.writeText`，仍可能因为非 HTTPS、非 localhost 或浏览器策略失败。失败时沿用第三天的“复制失败”提示和 1.5 秒超时策略。

无效分享链接、旧版本链接和损坏 payload 都不得抛出到 React 根节点，也不得载入部分损坏数据。

## 测试策略

### 材料与渲染

- 材料枚举包含蒸汽、熔岩和酸液，编号稳定为 `9`、`10`、`11`。
- `DRAWABLE_MATERIALS` 包含十一种可绘制材料，且橡皮仍单独处理。
- Renderer 能为三种新材料写入非透明像素。
- 空单元仍清零完整 RGBA。

### 蒸汽

- 蒸汽在随机值不触发冷凝时向上移动。
- 正上方受阻时按随机值选择斜上方向。
- `steamRoll < 0.08` 时蒸汽冷凝为水，且水同一步不继续移动。
- 蒸汽不会向下移动。

### 熔岩

- 熔岩四邻域遇水时，熔岩变石头，目标水变蒸汽。
- 熔岩遇多个水目标时选择目标可由测试随机源控制。
- 熔岩无水但邻近木头、油或植物时，将其中一个点燃为火。
- 熔岩点燃后本步不移动。
- `lavaMoveRoll >= 0.35` 时熔岩不移动。
- `lavaMoveRoll < 0.35` 时熔岩按液体规则移动。
- 新火、新蒸汽和新石头不会在同一步再次行动。

### 酸液

- 酸液腐蚀墙、石头、木头和植物时，酸液与目标一起消失。
- 酸液遇多个腐蚀目标时选择目标可由测试随机源控制。
- 酸液不腐蚀沙子、水、油、火、蒸汽、熔岩或酸液。
- 酸液无腐蚀目标时按液体规则流动。
- 腐蚀后的空位不会在同一步引发重复反应。

### 分享

- 新格式编码版本为 `2`。
- 版本 `2` 可以往返包含蒸汽、熔岩和酸液的网格。
- 版本 `1` 被拒绝并返回无效分享结果。
- 材料编号大于 `Material.Acid` 被拒绝。
- 宽高、PRNG 状态和下一步扫描方向继续严格往返。

### 界面与浏览器验收

- 页面显示“试验 04”。
- 材料栏显示蒸汽、熔岩和酸液按钮。
- 暂停、单步、清空和分享仍可用。
- 桌面视口无控制台错误。
- `390 x 844` 手机视口无整体横向溢出，材料栏可横向滚动。
- 可以画出水加熔岩产生蒸汽、酸液腐蚀墙、蒸汽上升的可展示场景。
