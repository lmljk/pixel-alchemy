# 第二天八种材料系统设计

## 目标

第二天把第一天的单一落沙 demo 扩展为可组合的像素炼金术沙盒。用户能够选择八种材料，观察固体、液体、火焰与植物之间产生清晰、可重复测试的反应，同时保留第一天已有的画笔、橡皮、暂停、键盘绘制和清空能力。

本阶段验证三个问题：

1. `Uint8Array` 网格能否继续承载多材料规则，而不引入 React 粒子状态。
2. 八种材料的移动与反应是否足够有趣，同时仍能用小型确定性测试描述。
3. 材料栏在桌面和 `390 x 844` 手机视口中是否保持易用。

## 第二天范围

### 包含

- 八种材料：
  - 沙子
  - 水
  - 墙
  - 石头
  - 木头
  - 油
  - 火
  - 植物
- 橡皮工具
- 材料名称、颜色、类别和可燃性集中定义
- 固体、液体和火焰的基础移动
- 水、油、火、木头和植物之间的最小反应
- 八种材料的可滚动材料栏
- 暂停或继续
- 清空
- 桌面和手机浏览器验收
- 每种材料规则的确定性单元测试

### 不包含

- 单步推进
- 分享种子或 URL 状态
- 保存、加载或作品库
- 撤销与重做
- 笔刷尺寸选择
- 温度、压力、密度场或连续流体
- 烟、蒸汽、灰烬等额外材料
- 后端、数据库、登录或上传

单步和分享种子留到第三天。原因是分享种子需要确定性随机源、初始状态序列化和版本兼容；这些工作应建立在稳定的材料规则之上。

## 材料模型

网格继续使用一维 `Uint8Array`。材料编号保持稳定：

| 编号 | 材料 | 类别 | 主要行为 |
| --- | --- | --- | --- |
| `0` | 空 | 空间 | 可被其他材料占据 |
| `1` | 沙子 | 粉末 | 下落，受阻后斜滑 |
| `2` | 水 | 液体 | 下落，受阻后横向流动 |
| `3` | 墙 | 固定固体 | 永不移动，不参与反应 |
| `4` | 石头 | 重固体 | 只垂直下落，不斜滑 |
| `5` | 木头 | 固定可燃固体 | 不移动，邻近火时着火 |
| `6` | 油 | 可燃液体 | 下落并横流，位于水上方，邻近火时着火 |
| `7` | 火 | 短寿命反应体 | 向上漂移，点燃可燃物，随机熄灭 |
| `8` | 植物 | 固定生长体 | 接触水时扩展，邻近火时着火 |

橡皮不是材料编号。界面选择橡皮时仍向 `paintCircle` 传入 `Material.Empty`。

## 材料目录

材料的展示信息和基础属性集中放在 `src/simulation/materials.ts`，而不是散落在 Toolbar、Renderer 和 Simulation 中。

每种可绘制材料提供：

- 稳定编号
- 中文标签
- CSS 标识
- 一到三组像素颜色
- 类别
- 是否可燃

对外提供按界面顺序排列的 `DRAWABLE_MATERIALS`。Toolbar 遍历该数组生成按钮，Renderer 从同一材料定义读取颜色。Simulation 仍使用明确的材料枚举分派物理规则，不构建过度通用的规则 DSL。

## 更新模型

### 双缓冲标记

第二天仍原地更新 `Uint8Array`，但增加一个与网格等长的步内标记数组。每次 `step()` 开始时清零标记：

- 材料移动到新位置后，目标位置标记为本步已处理。
- 扫描遇到已处理位置时跳过。
- 新生成的火或植物也标记为已处理。

这样可以防止液体或火焰在同一个模拟步内被重复移动或连续反应。

### 扫描顺序

每个模拟步从底部向顶部扫描，并在每步结束后交替左右方向。该顺序继续保证下落材料每步最多移动一格。

不同材料使用同一个网格扫描，但反应优先于移动：

1. 跳过空单元和本步已处理单元。
2. 执行当前材料的邻域反应。
3. 若材料仍存在，执行该材料的移动规则。
4. 标记移动目标或生成目标。

## 材料规则

### 沙子

沿用第一天规则：

1. 正下方为空时下落。
2. 否则按注入随机源决定的顺序检查左下和右下。
3. 移动到第一个空位置。
4. 三个方向都不可用时保持不动。

沙子不会穿过水或油。第二天不实现沉降置换。

### 水

水使用有限范围的离散流动：

1. 正下方为空时下落。
2. 正下方是油时与油交换，使水位于油下方。
3. 否则按随机顺序检查左下和右下空位。
4. 若斜下不可用，按同一优先方向在当前行搜索最多三格。
5. 水移动到遇到的第一个空位；遇到非空单元即停止该方向搜索。

有限三格搜索能形成明显铺展，又避免每粒液体每帧扫描整行。

### 墙

墙永不移动，也不会被水、油、火或植物改变。橡皮和清空仍可移除墙。

### 石头

石头只在正下方为空时下落一格。它不斜滑、不流动、不燃烧，也不与水或油交换。

### 木头

木头固定不动。若四邻域中存在火，木头在当前步变为火。

四邻域指上、下、左、右，不包含对角线。所有第二天邻接反应统一使用四邻域，减少含糊的角接触反应。

### 油

油使用与水相同的下落、斜下和最多三格横流规则，但存在两个差异：

1. 油不能与水交换；水负责向下穿过油，因此最终油浮在水上方。
2. 若四邻域中存在火，油在当前步变为火。

### 火

火不使用额外寿命数组，保持单字节网格模型：

1. 收集四邻域中的木头、油和植物。存在候选目标时，调用一次随机源选择并点燃其中一个；没有候选目标时不消耗该次随机值。
2. 调用一次随机源得到 `fireRoll`。当 `fireRoll < 0.18` 时，火熄灭为空。
3. 未熄灭时优先向正上方空位移动。
4. 正上方不可用时，使用同一个 `fireRoll` 决定斜向优先级：`fireRoll < 0.59` 时先左上，否则先右上。
5. 无可用位置时保持原位。

火每步最多消耗两次随机值：一次可选的点燃目标选择，一次必需的 `fireRoll`。具体调用顺序在测试中锁定，后续引入种子随机源时不得隐式增加调用。

### 植物

植物固定不动：

1. 若四邻域存在火，植物变为火，不再执行生长。
2. 否则若四邻域存在水，选择第一个与该水相邻的空格生成植物。
3. 生长成功后，将触发该次生长的水单元变为空。
4. 每个植物每步最多生成一个新植物。

候选水和空格的优先顺序由注入随机源确定。新植物标记为本步已处理，不能在同一步继续连锁生长。

## 随机源

继续使用构造参数注入 `RandomSource`。第二天不承诺不同浏览器或不同版本之间的可分享确定性，但所有规则测试必须使用固定随机序列。

新增一个测试辅助函数，用数组依次返回随机值；数组耗尽时返回最后一个值。这样测试可以明确表达：

- 左右方向选择
- 火是否熄灭
- 可燃目标选择
- 植物生长目标选择

第三天会把生产环境的 `Math.random` 替换为带种子的 PRNG，并定义 URL 序列化格式。

## 渲染

Renderer 根据材料定义写入像素颜色。每种材料使用稳定的少量颜色变化：

- 沙子：琥珀黄
- 水：蓝色
- 墙：深棕灰
- 石头：冷灰
- 木头：棕色
- 油：深金色
- 火：橙红色
- 植物：绿色

颜色变化只依赖网格索引和材料编号，不调用随机函数，因此同一网格每次渲染结果一致。

空单元继续清零完整 RGBA，避免复用 `ImageData` 时残留旧颜色。

## 界面

页面结构调整为：

1. 标题与“试验 02”
2. 方形 Canvas
3. 横向可滚动材料栏：沙子、水、墙、石头、木头、油、火、植物、橡皮
4. 操作栏：暂停或继续、清空

材料按钮使用颜色样本和中文名称，并通过 `aria-pressed` 表达当前选择。材料栏使用原生横向滚动，不隐藏滚动能力，不依赖拖拽插件。

### 桌面

- 材料栏可以完整显示或横向滚动。
- 操作栏保持两个等宽按钮。
- Canvas 仍是视觉主体。

### 手机

- 材料栏单行横向滚动，每个材料按钮宽度固定，不压缩到难以点击。
- 操作栏始终完整显示。
- 页面不产生整体横向滚动。
- 所有按钮高度不小于 `44px`。

## Canvas 与控制状态

`App` 继续持有当前工具和暂停状态。当前工具类型仍为 `Material`，因此不需要新建工具联合类型：

- 八种材料传入对应材料编号。
- 橡皮传入 `Material.Empty`。

暂停期间仍允许绘制所有材料。继续后，新绘制材料参与模拟。

键盘绘制继续使用当前材料。方向键移动笔尖，空格或回车绘制。

## 错误与边界

- 所有邻域访问通过 `getCell` 或边界检查，不读写无效索引。
- 液体横向搜索遇到边界时停止。
- 材料定义查询对未知编号返回安全的后备颜色，但 Simulation 不生成未知编号。
- 更新标记数组与网格尺寸始终一致。
- Canvas 卸载时继续取消动画帧。
- 本阶段不请求任何浏览器权限，也不访问网络。

## 测试策略

### 材料定义

- 八种可绘制材料顺序稳定且不包含空。
- 每种材料有非空中文名称、颜色和唯一编号。
- 可燃属性与木头、油、植物一致。

### Simulation

- 第一天下落、斜滑、擦除、清空和边界测试继续通过。
- 水下落、横流，并向下穿过油。
- 墙保持静止。
- 石头只垂直下落。
- 木头、油、植物邻火变火。
- 火点燃一个目标、上升并能熄灭。
- 植物消耗相邻水并只生长一次。
- 新生成或移动的单元同一步不会再次处理。

### Renderer

- 每种材料映射到预期基础颜色和不透明 alpha。
- 材料被擦除后完整清零 RGBA。

### Toolbar 与 App

- 九个材料或橡皮按钮可访问且切换正确。
- 当前材料使用 `aria-pressed`。
- 暂停、继续和清空行为保留。
- 页面阶段标签更新为“试验 02”。

### 浏览器验收

- 依次绘制八种材料，颜色和行为可辨认。
- 水和油形成分层。
- 火能点燃木头、油和植物并熄灭。
- 植物接触水后生长。
- 暂停期间所有材料保持静止但仍可绘制。
- 橡皮和清空有效。
- 桌面和 `390 x 844` 手机视口无整体横向溢出。
- 手机材料栏可横向滚动，操作栏始终可见。
- 控制台无相关错误或警告。

## 第二天完成标准

以下条件全部满足才算第二天完成：

- 八种材料均可绘制并具有可辨认行为。
- 所有材料反应具有确定性单元测试。
- 第一天下落、画笔、暂停、擦除和清空没有回归。
- 全量测试和生产构建通过。
- 桌面和手机浏览器核心交互通过。
- 没有引入后端、数据库、特殊权限或网络依赖。
- 架构允许第三天增加单步和带种子分享，而无需重写材料规则。
