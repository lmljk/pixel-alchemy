# 第一天可玩沙盒设计

## 目标

第一天交付一个可以直接游玩的像素沙盒雏形。用户能够绘制沙子、观察沙子受重力下落和堆积、擦除粒子、暂停或继续模拟，并清空画布。

本阶段验证三个核心问题：

1. Canvas 粒子模拟在桌面和手机浏览器中是否稳定。
2. React 界面与高频动画循环能否保持清晰边界。
3. 后续增加 8 种材料、单步和分享种子时是否无需推倒重来。

## 范围

### 包含

- 方形像素画布
- `160 x 160` 粒子网格
- 沙子下落、堆积和斜向滑落
- 鼠标与单指触摸绘制
- 连续笔画插值
- 沙子工具
- 橡皮擦工具
- 暂停与继续
- 清空画布
- 移动端优先的底部工具栏
- 桌面与 `390 x 844` 手机视口适配
- 物理引擎单元测试
- 浏览器交互验收

### 不包含

- 水、墙、石、木、火、油、植物等后续材料
- 单步推进
- 分享种子
- 撤销与重做
- 笔刷尺寸选择
- Rust 或 WebAssembly
- Firebase、数据库、登录和作品上传
- Docker

## 技术方案

项目使用 React、TypeScript、Vite 和 Canvas 2D。

React 只管理低频界面状态：

- 当前工具
- 暂停状态
- 清空命令

粒子网格不进入 React state。模拟引擎持有一个 `Uint8Array`，Canvas 组件通过引用访问引擎，并在 `requestAnimationFrame` 中推进和绘制。这样粒子每帧变化不会触发 React 组件树重渲染。

## 模块边界

### `Simulation`

职责：

- 创建和持有粒子网格
- 读写网格单元
- 推进一次固定模拟步
- 绘制或擦除圆形区域
- 清空网格

依赖：

- 网格尺寸
- 可注入的随机函数

它不依赖 React、DOM 或 Canvas，因此可以在 Node 测试环境中直接测试。

### `SandboxCanvas`

职责：

- 创建并持有 `Simulation` 实例
- 运行固定时间步动画循环
- 将网格绘制到 Canvas
- 把指针坐标转换为网格坐标
- 对连续指针位置插值并调用引擎绘制

它不保存逐粒子 React 状态。

### `Toolbar`

职责：

- 切换沙子和橡皮工具
- 暂停或继续
- 请求清空
- 表达当前选中状态

### `App`

职责：

- 组合标题、画布和工具栏
- 持有当前工具与暂停状态
- 将清空操作传给画布

`App` 不实现粒子规则或 Canvas 绘制细节。

## 数据模型

网格使用一维 `Uint8Array`：

- `0`：空
- `1`：沙子

坐标 `(x, y)` 的索引为 `y * width + x`。

第一天只需要两个值，但材料编号会保持可扩展，后续可以继续增加而不更换容器。

## 模拟规则

每次固定模拟步从底部向顶部更新：

1. 若当前单元不是沙子，则跳过。
2. 若正下方为空，沙子向下移动一格。
3. 否则按照随机顺序检查左下和右下。
4. 第一个为空的位置接收沙子。
5. 三个方向都被阻挡时，沙子保持原位。

每个模拟步交替横向扫描方向，减少稳定沙堆向单侧偏斜。

随机函数通过构造参数注入。生产环境使用普通随机源；测试使用固定序列。完整的可分享确定性种子在后续阶段实现。

## 时间与动画

使用 `requestAnimationFrame` 驱动渲染，并通过累计时间执行固定步长模拟：

- 固定模拟步长：约 `1 / 60` 秒
- 每帧限制最大补算步数
- 页面切入后台后不累计大段时间
- 暂停时继续渲染，但不推进模拟

暂停期间仍允许绘制。继续后，新绘制的沙子恢复参与模拟。

## 输入处理

使用 Pointer Events 统一鼠标和触摸输入：

- `pointerdown` 开始绘制并捕获指针
- `pointermove` 在按下状态下连续绘制
- `pointerup` 或 `pointercancel` 结束绘制

相邻采样点之间使用线段插值，防止快速拖动出现断裂。转换后的坐标必须限制在网格边界内，画布外输入不会写入无效索引。

第一天使用固定小笔刷，笔刷尺寸选择留到后续。

## 视觉设计

视觉方向为“温暖手账”：

- 页面背景：浅米色
- 画布背景：暖白色
- 主文字和边框：深棕色
- 沙粒：琥珀色，并允许少量稳定色差
- 阴影：短距离硬边阴影
- 按钮：简洁矩形，不使用玻璃、霓虹或胶囊标签

页面结构：

1. 顶部显示“像素炼金术”和简短阶段标识。
2. 中间为尽可能大的方形画布。
3. 底部为沙子、橡皮、暂停或继续、清空四个操作。

手机采用底部横向工具栏。桌面保持相同信息结构，不切换为右侧栏。

不使用外部字体或图片素材，避免网络加载影响 demo。

## 可访问性

- 所有工具均使用原生按钮
- 当前材料使用 `aria-pressed`
- 暂停按钮具有明确可读文本
- Canvas 提供可访问名称和简短说明
- 键盘焦点具有明显轮廓
- 颜色不是选中状态的唯一提示
- 触摸目标不小于约 44 像素

## 错误与资源清理

- 所有网格读写检查边界
- 无效坐标被忽略
- Canvas 组件卸载时取消动画帧
- 指针取消时结束绘制状态
- 清空操作不会重建 React 页面
- 不请求相机、文件、剪贴板、通知或位置权限

## 测试策略

### 单元测试

按测试驱动方式覆盖：

1. 沙子在下方为空时下降一格。
2. 沙子正下方被挡时向可用斜下方移动。
3. 沙子三个方向均被挡时保持不动。
4. 擦除操作清除目标区域。
5. 清空操作移除所有粒子。
6. 越界绘制不会抛错或污染有效网格。

### 浏览器验收

在 Chromium 中验证：

- 页面和 Canvas 正常显示
- 沙子笔画连续
- 沙子会自然下落和堆积
- 暂停后粒子停止
- 暂停期间仍可绘制
- 继续后粒子恢复移动
- 橡皮擦有效
- 清空有效
- 控制台无相关错误
- `390 x 844` 视口无横向溢出或关键控件遮挡
