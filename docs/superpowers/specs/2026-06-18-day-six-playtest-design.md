# 第六天试玩增强设计

## 目标

第六天把已经发布到 GitHub 的像素炼金术 demo 变得更容易试玩。用户不需要先理解每种材料的搭配，也能通过示例场景看到最有趣的反应；同时用户可以调整笔刷大小，更快画出大块结构。

本阶段不扩展底层物理，不新增材料，不修改分享格式，重点是改善“打开就会玩”的体验。

## 状态与组件设计

`App` 继续持有交互状态，并新增：

- `brushRadius`
- 当前示例场景加载函数

`SandboxCanvas` 接收 `brushRadius` prop，并用它替换当前内部固定的 `BRUSH_RADIUS = 2`。键盘绘制、鼠标绘制和触控绘制都使用同一半径。

`Toolbar` 增加两个控制组：

1. 笔刷大小组：一个 `1..8` 的滑块和当前值文本
2. 示例场景组：熔岩遇水、酸液腐蚀、植物生长、油火反应

现有材料栏和操作栏保持不变。滑块在窄屏下占一整行，避免按钮过多挤占手机空间；材料栏继续横向滚动。

## 示例场景设计

新增 `src/simulation/exampleScenes.ts`，集中定义示例场景，避免把场景坐标散落在 `App` 或 `Toolbar` 里。

对外提供：

- `ExampleSceneId`
- `EXAMPLE_SCENES`
- `applyExampleScene(simulation, sceneId)`

场景使用现有 `Simulation.clear()` 和 `Simulation.paintCircle()` 绘制，不绕过公开 API。这样测试和真实 UI 走同一条路径。

### 熔岩遇水

画布中间偏左放水，偏右放熔岩，中间留少量接触空间。用户单步后应看到蒸汽和石头产生。

### 酸液腐蚀

画布中间放一小段墙和石头，旁边放酸液。用户单步后会看到酸液与目标一起消失。

### 植物生长

画布中间放植物和相邻水，周围留空。用户单步后可以看到植物消耗水并扩展。

### 油火反应

画布中间放油池，旁边放火。用户单步后可以看到火点燃油，并继续上漂或熄灭。

## 随机与分享

示例场景不重置 `SeededRandom` 状态，只改变画布内容。原因是：

- 当前分享链接已经保存随机状态。
- 示例场景只是试玩入口，不要求每次从完全相同随机状态开始。
- 不新增随机源控制可以保持实现简单。

点击示例场景后分享仍然可用。分享链接保存示例画布、当前随机状态和扫描方向，格式继续为 `v2`。

## 测试策略

### 示例场景

- 每个场景可以清空已有画布。
- 每个场景会绘制预期材料组合。
- 场景函数只使用现有材料编号，不改变网格尺寸。

### 笔刷大小

- `SandboxCanvas` 使用传入的 `brushRadius` 绘制。
- 滑块最小值为 `1`，最大值为 `8`，默认值为 `2`。
- 调大滑块后绘制的非空单元数量多于较小半径。

### Toolbar

- 渲染笔刷滑块。
- 滑块显示当前笔刷半径。
- 调整滑块会调用 `onBrushRadiusChange`。
- 渲染四个示例场景按钮。
- 点击示例场景按钮会调用 `onExampleSceneSelect`。

### App

- 页面显示“试验 06”。
- 页面显示试玩提示。
- 点击示例场景后切换到暂停状态。
- 示例场景按钮存在，且不会破坏材料选择、暂停、单步、清空和分享。
